Subtitle repository

Nothing here needs changing. The extension is already set up and works as soon as it is installed. These fields only matter if you host your own subtitles somewhere else — it reads index.json from the repository root.

A custom host needs one-time permission, which Chrome will prompt for when you save.

Player access

Not needed for now. The current player host is already covered by the extension, so subtitles work without granting anything.

Anikoto loads the video from a third-party player whose host changes from time to time. If it changes to one the extension does not know, subtitles stop appearing until you grant access below. This is broad access — any HTTPS site — so grant it only if you are comfortable with that, and only when subtitles have actually stopped working.
